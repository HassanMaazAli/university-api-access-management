Core Architectural Features

SHA-256 Hashing

No plaintext API keys in the database. Keys are hashed with SHA-256; only prefixes are shown.

Key-Derived Identity

Server derives student identity strictly from the verified key hash. Client-supplied IDs are completely ignored.

Atomic Quota Control

Atomic SQL updates ensure accurate concurrency-safe request counting and instant 429 enforcement.

Audit Logging

All authenticated and rejected requests are automatically recorded in api_request_logs.
